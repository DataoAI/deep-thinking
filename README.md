# Deep Thinking — AI深度思考框架

> 🌐 [English](./README.en.md)

让AI在回答任何问题之前，先经过一个系统化的深度思考过程，而不是直接给出表层答案。

---

## 痛点 / Problem

当你问AI一个复杂问题，它往往会立刻给出一个"听起来合理"的答案——因为这个答案是最"可能"的，不是最"正确"的。

根源在于：**AI的默认思考路径是"直给"。** 面对问题，它倾向于直接跳到最可能的答案，而不是先探索问题的多面性。这就像一个人在信息不充分时抢答——答得快，但经常答浅、答偏。

而人类专家面对复杂问题时，路径完全不同：先停下来理解问题 → 拆解成可处理的部分 → 并行考虑多种可能 → 质疑自己的第一反应 → 验证哪个站得住 → 最后才组织回答。

**这个技能要做的事很简单：给AI装上一个"专家思考流程"，让它在回答之前，先像一个资深专家那样想一遍。**

---

## 设计理念 / Design Philosophy

### 为什么是这6步

Deep Thinking 不是拍脑袋想出来的6个步骤，而是**把人类专家的隐性思考过程，显性化为AI可执行的框架**。

| 步骤 | 人类专家的隐性行为 | 解决的AI缺陷 |
|:----:|:-----------------|:------------|
| 1. 重述 Restate | "让我先确认我理解对了" | AI经常不确认就开答，理解偏了却不知道 |
| 2. 分解 Decompose | "这个问题太大，我拆开看" | AI面对复杂问题一口吞下，抓不住重点 |
| 3. 多假设 Hypothesize | "可能有几种情况，我都想想" | AI只给最可能的答案，忽略其他可能 |
| 4. 质疑 Challenge | "我的第一反应对吗？反过来呢？" | AI的第一反应往往是表面答案 |
| 5. 验证 Verify | "让我检验一下哪个站得住" | AI想当然，不验证就下结论 |
| 6. 整合 Synthesize | "我把思路整理清楚再回答" | AI分析了一堆，但说不清楚 |

**核心洞察：** 这6步不是给AI增加负担，而是**纠正它的默认路径**——从"直线抢答"变为"网状探索"。复杂问题需要的是后者。

### 为什么"重述"是第一步

很多人忽略重述的价值。但大多数AI回答错误，根源是**理解偏差**——它没听懂问题，就急着给答案。重述这一关，用最小的成本换最大的正确率。

### 设计原则

- **不做硬性模板**：这6步是思考路径，不是答题格式。AI不需要输出"第1步...第2步..."，只需在内部走完路径，输出整合后的结果。
- **先判断，再决定深度**：即使简单问题，也要先经过框架检验——确认问题确实简单，才可快速回答。这是"判断过程"，不是"自动跳过"。

---

## 什么是Deep Thinking

Deep Thinking 是一个结构化的思考框架，要求AI在输出最终回答之前，依次经过6个步骤：

| 步骤 | 英文 | 说明 |
|:----:|:----|:----|
| 1 | Restate | 重述问题，确认理解正确 |
| 2 | Decompose | 分解问题，拆成可处理的部分 |
| 3 | Hypothesize | 多假设并行，不只找"一个答案" |
| 4 | Challenge | 质疑初始假设，推翻自己的第一反应 |
| 5 | Verify | 测试与验证，用逻辑检验哪个假设站得住 |
| 6 | Synthesize | 整合结论，把分析过程变成清晰的回答 |

这6步不是硬性的模版，而是让AI的思考路径从"直线"变成"网状"。

## 安装方式 / Installation

### 作为Claude Code技能

将 `SKILL.md` 放入以下任一目录即可：

**Claude Code技能目录（所有项目可用）：**
```
# Windows
C:\Users\你的用户名\.claude\skills\deep-thinking\SKILL.md

# macOS / Linux
~/.claude/skills/deep-thinking/SKILL.md
```

**Agent全局技能目录（跨环境使用）：**
```
# Windows
C:\Users\你的用户名\.agents\skills\deep-thinking\SKILL.md

# macOS / Linux
~/.agents/skills/deep-thinking/SKILL.md
```

> 提示：将 `你的用户名` 替换为你电脑上的实际用户名。例如 `C:\Users\zhangsan\.claude\skills\deep-thinking\SKILL.md`

### 作为独立提示词

直接将 `自述版.md` 的内容复制到对话中，AI会按照框架深度思考。

---

## 建议：配置为强制执行

如果你希望AI**每次响应前都自动执行深度思考**（而不是每次手动粘贴），可以在你的 `CLAUDE.md` 或 `AGENT.md` 规则文件中加入以下内容：

```markdown
## ⛔ 第零条铁律：深度思考先于一切

**做任何事之前，必须先调用深度思考框架，再输出回答。**

跳过思考直接执行 = 严重违规
```

> 如果觉得每次都用太繁琐，也可以加一条例外规则：用户说"快速回答"或"简单回复"时可以跳过。

## 最佳配合：思路碰撞（Deep Question）

Deep Thinking 负责"想清楚"，[思路碰撞（Deep Question）](https://github.com/DataoAI/deep-question) 负责"说明白"。

实际使用中，它们是**循环配合**的：

1. 你有一个模糊的想法 → 先用 Deep Thinking 自己深度思考，理出大概方向和问题
2. 拿着这个方向去跟AI思路碰撞，在对话中进一步澄清
3. 碰撞中产生新的问题 → 再让AI深度思考一轮
4. 再碰撞、再思考...

**思考→碰撞→再思考→再碰撞**，每一次循环，思路就更清晰一层。
